# Ashwin Parambil — Personal Portfolio

Live at: [ashwinparambil.github.io](https://ashwinparambil.github.io)

A futuristic, single-file personal portfolio website built with vanilla HTML, CSS, and JavaScript. No frameworks, no build tools, no dependencies — just one `index.html` file deployed via GitHub Pages.

---

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Markup | HTML5 |
| Styling | CSS3 (custom — glassmorphism, animations, grid) |
| Scripting | Vanilla JavaScript (ES6+) |
| Fonts | Orbitron, Inter, JetBrains Mono (Google Fonts) |
| Hosting | GitHub Pages |

---

## Features

- Cyberpunk / sci-fi HUD aesthetic with neon cyan, violet, and magenta palette
- Custom crosshair cursor with lagging ring effect
- Animated ambient glow blobs with mouse parallax
- Perspective grid background with scanline overlay
- Spinning orbit rings in the hero section
- Scroll-triggered animated skill bars
- Bento grid layout for About section
- Intersection Observer scroll-reveal animations on all sections
- Fully responsive and mobile-friendly

## Running Locally

No setup required. Just open the file in any browser:

```bash
git clone https://github.com/ashwinparambil/ashwinparambil.github.io.git
cd ashwinparambil.github.io
open index.html        # macOS
# or drag index.html directly into your browser
```
